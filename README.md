**AI Interview Master** is a smart application that helps job seekers prepare for technical and HR interviews using **AI-powered mock interviews, instant feedback, and progress tracking**. The app is **hosted on Streamlit**, so you can run it instantly in your browser without setup.

## Features ✨

* **AI-Powered Mock Interviews**: Simulate real interviews for tech and HR roles.
* **Extensive Question Bank**: Curated technical and behavioral questions.
* **Instant Feedback**: Get AI suggestions on answers, clarity, and confidence.
* **Progress Tracking**: Monitor improvements over time.
* **Customizable Practice**: Pick topics, difficulty, or company-specific questions.
* **Resume & LinkedIn Guidance**: AI suggestions to improve your professional profile.

---

## Technologies 🛠

* **Backend & AI**: Python, OpenAI GPT APIs, NLP models
* **Frontend**: Streamlit
* **Database**: MongoDB / MySQL (optional)
* **Deployment**: Streamlit Cloud

## Installation 💻

To run locally:

```bash
# Clone the repository
git clone https://github.com/yourusername/AI-Interview-Master.git
cd AI-Interview-Master

# Install dependencies
pip install -r requirements.txt

# Run the Streamlit app
streamlit run app.py
```

---

## Usage 🎯

1. Open the app in your browser (either via Streamlit Cloud or locally).
2. Sign up or log in.
3. Select the interview type (Technical / HR / Mixed).
4. Start the mock interview and answer questions.
5. Receive instant AI feedback.
6. Track your progress and revisit topics for improvement.
